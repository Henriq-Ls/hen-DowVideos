────────────────────────────────────────────────────────────────────────────────
BUGS CLÁSSICOS DO PYSIDE6 — JÁ PROTEGIDOS AQUI, NÃO REPITA FORA:
────────────────────────────────────────────────────────────────────────────────
  ✗ NUNCA crie QTimer sem pai → sempre QTimer(self) ou QTimer(parent)
    Motivo: timer sem pai não é destruído automaticamente → vaza memória.

  ✗ NUNCA conecte lambda diretamente a sinal em PySide6 6.6+
    Motivo: incrementa refcount e nunca libera → leak silencioso.
    Errado:  btn.clicked.connect(lambda: self.fazer_algo())
    Certo:   btn.clicked.connect(self._ao_clicar_btn)

  ✗ NUNCA esqueça de desconectar sinais antes de destruir objetos dinâmicos
    Motivo: objeto conectado a sinal não é coletado pelo GC → vaza memória.
    Certo:  no closeEvent ou __del__, chame signal.disconnect() antes de deletar.

  ✗ NUNCA modifique widgets fora da main thread
    Motivo: Qt não é thread-safe para UI → crash imprevisível.
    Certo:  emita um sinal da thread, conecte a um slot na main thread.

O QUE ESTE TEMPLATE JÁ CONTÉM (não recrie, não modifique a estrutura):
────────────────────────────────────────────────────────────────────────────────

main.py
  Ponto de entrada. Sequência de bootstrap já definida:
  faulthandler → logger → appdata → excepthook → QApplication → MainWindow
  NÃO altere a ordem. Só troque NOME_DO_PROJETO pelo nome real.

_CONFIGURA_/__init__.py
  Fonte única de verdade para TODOS os hardcodes.
  Substitua os valores de NOME_DO_PROJETO, cores, dimensões e atalhos
  conforme o projeto. Adicione novas constantes aqui. NUNCA em outro lugar.

_LOGS_/log.py
  Logger singleton. COPIE SEM ALTERAR para qualquer projeto.
  Uso: from _LOGS_ import log

_APPDATA_/gerenciador.py
  Singleton do AppData. Troque "nome_do_projeto" em PASTA_APPDATA (vem de
  _CONFIGURA_). O resto é idêntico em todos os projetos.

_THREADS_/thread_segura.py
  Base class obrigatória para QThread. COPIE SEM ALTERAR.
  Nenhum arquivo do projeto pode herdar QThread diretamente.

_THREADS_/thread_manager.py
  Gerenciador central de threads. COPIE SEM ALTERAR.
  Registra, monitora e encerra todas as threads no shutdown.

_APP_/main_window.py
  Esqueleto da janela principal. EXPANDA conforme o projeto.
  Adicione painéis, menus e widgets específicos aqui ou em subpastas de _APP_.

_ULTILIDADES_/icones.py
  Centraliza ícones via qtawesome. Adicione ícones novos aqui.

_ULTILIDADES_/popups.py
  Diálogos padronizados (erro, aviso, confirmação, perigo). Expanda conforme necessário.

_ULTILIDADES_/loading_overlay.py
  Overlay modal animado para operações demoradas (carregamento, processamento).
  Bloqueia toda interação até fechar() ser chamado.
  Spinner puro QPainter — sem GIF, sem dependência externa.
  Cores puxadas de _CONFIGURA_. Thread-safe: fechar() pode ser conectado a Signal.
